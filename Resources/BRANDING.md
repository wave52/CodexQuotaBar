# CodexQuotaBar icon

Generated with the built-in imagegen tool on 2026-09-22.
Reference: a local logo image (palette and folded geometric style only).

Design prompt: Q-shaped segmented quota ring and three ascending bars. Bold vector-like geometry, generous negative space, subtle folded orange shading, no text, full square charcoal background. Orange #FF9900, charcoal #414141 / #4B4B4B, darker orange #E58A00. Native macOS utility icon, readable at small sizes.

`AppIcon.png` is the generated master. `bash scripts/build-icon.sh` creates the standard 16–1024 pixel ICNS family using sips and iconutil. The build script packages AppIcon.icns; the app uses the same identity in the menu bar and header.
